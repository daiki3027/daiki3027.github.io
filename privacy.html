Privacy Policy — rclone personal Drive sync

1. 本ポリシーの対象

本ポリシーは、rclone を個人のファイルバックアップ目的で利用するために 作成された個人用 Google OAuth クライアント（以下「本アプリ」）に適用されます。 本アプリの利用者は作成者本人のみであり、第三者に配布・提供していません。

2. 取得する情報とその範囲

本アプリは Google OAuth を通じて、作成者本人の Google ドライブへのアクセス権限を取得します。 取得した権限は、作成者自身のファイルをアップロード・ダウンロード・同期する目的にのみ使用します。

  • 本アプリは、作成者本人以外のアカウントにアクセスしません。
  • 本アプリは、広告・解析・プロファイリングのための情報収集を一切行いません。

3. 情報の保存場所

アクセストークンおよびリフレッシュトークンは、作成者のローカル端末上の rclone 設定ファイル （~/.config/rclone/rclone.conf）にのみ保存されます。 同期対象のファイルは、作成者のローカル端末と作成者自身の Google ドライブとの間でのみ転送されます。

4. 第三者への提供

本アプリは、取得した情報を第三者に送信・提供・販売しません。 Google API から取得した情報は、Google の API Services User Data Policy （Limited Use requirements を含む）に従って取り扱います。

5. データの削除・アクセス権の取り消し

本アプリへのアクセス権限は、Google アカウントの権限設定 からいつでも取り消すことができます。権限を取り消した時点で、本アプリは Google ドライブへアクセスできなくなります。 ローカルに保存されたトークンは、rclone 設定ファイルを削除することで消去されます。

6. お問い合わせ

本ポリシーに関するお問い合わせ先: daikei333@gmail.com

Privacy Policy (English)

1. Scope

This policy applies to a personal-use Google OAuth client created to use rclone for backing up the author's own files. The application is used solely by its author and is not distributed to anyone else.

2. Information accessed

The application requests access to the author's own Google Drive via Google OAuth. This access is used only to upload, download and synchronise the author's own files. It never accesses any other person's account, and it performs no collection of data for advertising, analytics or profiling purposes.

3. Storage

Access and refresh tokens are stored only in the rclone configuration file (~/.config/rclone/rclone.conf) on the author's local machine. Files are transferred only between the author's local machine and the author's own Google Drive.

4. Disclosure to third parties

No information is transmitted, sold or otherwise provided to any third party. Information obtained from Google APIs is handled in accordance with the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

Access can be revoked at any time from Google Account permissions. Locally stored tokens are removed by deleting the rclone configuration file.

6. Contact

Questions about this policy: daikei333@gmail.com
