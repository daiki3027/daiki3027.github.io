rclone personal Drive sync

個人利用のための rclone + Google Drive 連携 / Personal rclone setup for Google Drive

概要

このページは、rclone（オープンソースのファイル同期ツール）を 個人のファイルバックアップ目的で使うために作成した、個人用 Google OAuth クライアントの ホームページです。Google OAuth 同意画面の要件を満たすために公開しています。

このアプリについて

  • 利用者は作成者本人のみです。第三者に配布・提供していません。
  • 作成者自身の Google ドライブに対して、ファイルのアップロードおよび同期を行います。
  • 処理はすべて作成者のローカル端末上で動作する rclone によって実行されます。サーバーは介在しません。
  • 収集・保存・送信を行うバックエンドは存在しません。

About

This site is the homepage for a personal-use Google OAuth client used with rclone, an open-source file synchronisation tool. It is operated by a single individual for the sole purpose of backing up that individual's own files to their own Google Drive. The application is not distributed to, or used by, anyone else, and there is no server-side component that collects or stores any data.
